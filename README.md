# ಸ್ಮಾರ್ಟ್ ಕನ್ನಡ ಕಲಿಕೆ — Streamlit MVP

## Windows ನಲ್ಲಿ ಚಾಲನೆ

1. Python 3.11 ಅಥವಾ 3.12 ಇನ್‌ಸ್ಟಾಲ್ ಮಾಡಿ.
2. ಈ ಫೋಲ್ಡರ್ ಅನ್ನು ತೆರೆಯಿರಿ.
3. Command Prompt ಅಥವಾ VS Code terminal ತೆರೆಯಿರಿ.
4. ಕೆಳಗಿನ commands ಚಲಾಯಿಸಿ:

```bash
python -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements.txt
streamlit run app.py
```

5. ಬ್ರೌಸರ್‌ನಲ್ಲಿ `http://localhost:8501` ತೆರೆಯುತ್ತದೆ.

## ಮುಖ್ಯ ಸೂಚನೆಗಳು
- ಇದು ಪ್ರಾರಂಭಿಕ MVP; ಎಲ್ಲಾ ವಿಷಯಗಳು sample content ಆಗಿವೆ.
- ಕಲಿಕಾ ಪ್ರಗತಿ ಪ್ರಸ್ತುತ Streamlit session ನಲ್ಲಿ ಮಾತ್ರ ಉಳಿಯುತ್ತದೆ.
- Google Fonts ಬಳಸುವಾಗ ಇಂಟರ್ನೆಟ್ ಇದ್ದರೆ Noto Sans Kannada ಫಾಂಟ್ ಲೋಡ್ ಆಗುತ್ತದೆ; ಇಲ್ಲದಿದ್ದರೆ ಸಿಸ್ಟಮ್ ಫಾಂಟ್ ಬಳಸಲಾಗುತ್ತದೆ.
- ಪದಗಳ ಅಕ್ಷರ ಎಣಿಕೆ, ಒತ್ತಕ್ಷರ ವರ್ಗೀಕರಣ ಮತ್ತು ಸಾಮಾನ್ಯ ಜ್ಞಾನ ವಿಷಯಗಳನ್ನು ಪ್ರಕಟಿಸುವ ಮೊದಲು ಕನ್ನಡ ಶಿಕ್ಷಕರಿಂದ ಪರಿಶೀಲಿಸಿ.
